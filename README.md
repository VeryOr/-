구현 내역

1단계: 프로젝트 기본 환경 설정 및 공통 리소스(common, css, js, data) 구성

2단계: 경험 채우기 메인 페이지(index.html) 및 기본 화면 레이아웃 구현

3단계: 경험 상세 정보 확인을 위한 상세 페이지(fill-detail.html) 구현

4단계: 경험 참여 및 관련 정보를 입력하는 참여 페이지(fill-participate.html) 구현

5단계: 사용자에게 적합한 경험 및 활동을 탐색하는 추천 페이지(fill-recommend.html) 구현

6단계: 관심 있는 경험 및 활동을 저장하고 관리하는 스크랩 페이지(fill-scrap.html) 구현

7단계: 경험 및 역량을 정리하는 포트폴리오 페이지(portfolio-star.html) 구현

최종 정리: 페이지별 HTML 파일 분리 및 공통 CSS·JavaScript·데이터 리소스 구성


사용 오픈소스

Day.js: 공고 마감일 계산 및 D-Day 표시

Fuse.js: 공고 제목, 주최 기관, 분야 및 태그에 대한 오타 허용(퍼지) 검색

HTML5 / CSS3: 웹페이지 구조 및 사용자 인터페이스 구성

JavaScript: 공고 추천, 직무 역량 매칭, 경험 기록 및 스크랩 관리 기능 구현

LocalStorage: 사용자 정보, 경험 기록, 스크랩 목록 및 진행 상태 저장
